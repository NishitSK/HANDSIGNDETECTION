MediaPipe Web vs Python landmarks

Runs MediaPipe Web on held-out test photos, compares its landmarks with the Python extraction the model was trained on, and checks whether the browser pipeline predicts the same letter as Keras. Open it through python mobile/serve_https.py --test. Options: ?perClass=2 (photos per letter), ?model=../app/model/isl/model.json, ?features=126 (126 = hands only, 186 = hands + face), ?keras=hands_only (matches the keras_probs_<keras>.f32 file from export_reference.py).
